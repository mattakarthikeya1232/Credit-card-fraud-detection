# Credit Card Fraud Detection Dashboard

React + Vite demo for a college project. Mock transactions are in one clearly marked array in `src/TransactionHistory.jsx`.

## Run
1. Install Node.js LTS from https://nodejs.org/.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`, then open the localhost URL Vite prints.

## Publish to GitHub
Create an empty GitHub repository, then from this folder:

```bash
git init
git add .
git commit -m "Build transaction fraud dashboard"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
git push -u origin main
```
Replace the example URL with your repository URL.
